# microCMS 連携の設定手順

サイトの「トップ写真・ABOUT・COURSE・PHOTO」を microCMS の管理画面から編集できるようにする手順です。
サーバー（エックスサーバー）側の変更は不要です。

## 1. microCMS でサービスを作成

1. https://microcms.io/ でアカウントを作成（無料プラン）
2. 「サービスを作成」→ サービス名は任意（例: AILE）、サービスIDも任意（例: `aile-salon`）
   - サービスIDは後で `js/cms.js` に書くので控えておく

## 2. API を4つ作成（すべて「リスト形式」）

「API を作成」→ 名前とエンドポイントを入力 → **リスト形式** を選択 → フィールドを追加。

### TOP（トップ写真）
- エンドポイント: `top`

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `image` | 写真（PC・スマホ共通） | 画像 | ○ |
| `image_sp` | スマホで切れ方が気になる時だけ：スマホ用の写真（任意） | 画像 | |
| `order` | 表示順 | 数字 | |

`image_sp` の説明文（フィールド設定の「説明文」欄）:
「通常は空のままで大丈夫です。スマホで人物が切れてしまう場合だけ、縦長に切り抜いた写真をここに入れると、スマホではこちらが表示されます。」

基本は `image` 1枚をPC・スマホ共通で使い、スマホでは中央を自動で切り抜きます。

### ABOUT
- エンドポイント: `about`

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `image` | 写真 | 画像 | ○ |
| `title` | 見出し | テキストエリア（改行可） | ○ |
| `body` | 本文 | テキストエリア | |
| `order` | 表示順 | 数字 | |

### COURSE
- エンドポイント: `course`

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `name` | コース名 | テキストフィールド | ○ |
| `description` | 説明文 | テキストエリア | |
| `price` | 料金（1行に1つ） | テキストエリア | |
| `order` | 表示順 | 数字 | |

### PHOTO（フォトギャラリー）
- エンドポイント: `photo`

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `image` | 写真 | 画像 | ○ |
| `order` | 表示順 | 数字 | |

> フィールドIDは大文字小文字を含めて上の通りにしてください（コードがこの名前で読みます）。

## 3. APIキーを作成（読み取り専用）

1. 左メニュー「APIキー」→「作成」
2. デフォルト権限で **GET だけ** にチェック（POST / PUT / PATCH / DELETE は外す）
3. 発行されたキーを控える

このキーはサイトのJSに書くため誰でも見られますが、GET のみなので「公開済みの内容を読む」以外はできません。

## 4. サイト側にサービスIDとキーを設定

`js/cms.js` の先頭付近を書き換えます。

```js
var CMS_CONFIG = {
  serviceId: 'aile-salon',       // ← サービスID
  apiKey: 'xxxxxxxxxxxxxxxxxxxx' // ← GET のみの APIキー
};
```

両方を入れたうえで `index.html` `js/cms.js` `js/main.js` をサーバーにアップロードすると連携が有効になります。
両方空のままなら、これまでどおり HTML に書かれた内容が表示されます。

## 5. 動作の仕組みと注意

- ページを開くと microCMS から内容を取得し、各セクションを差し替えます。
- 取得に失敗した場合（通信エラー・キー間違いなど）は HTML の内容がそのまま表示されるので、サイトが真っ白になることはありません。
- 表示順は `order` の数値が小さい順です。未入力は最後に回ります。
- 写真は microCMS 側で自動的にリサイズ・軽量化（WebP）されて配信されます。元の大きさのままアップロードして構いません。
- 1つのAPIにつき最大100件まで読み込みます。

## 6. ローカルでの動作確認

サーバーを立てて `?cms=mock` を付けて開くと、`cms-mock/*.json` の内容で差し替え動作を確認できます。

```bash
python3 -m http.server 8765
# → http://127.0.0.1:8765/index.html?cms=mock
```

## 7. クライアント向け: 日々の更新のしかた

1. https://microcms.io/ にログイン
2. 左メニューから「TOP / ABOUT / COURSE / PHOTO」のいずれかを開く
3. 「追加」で新規、既存の行をクリックで編集、「削除」で削除
4. 「公開」を押す → サイトを再読み込みすると反映

推奨: パスワードは使い回さず、アカウント設定から2段階認証をオンにしてください。
